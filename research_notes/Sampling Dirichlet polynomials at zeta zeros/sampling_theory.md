# Sampling, Marcinkiewicz–Zygmund and frame theory for Dirichlet polynomials, and zeta zeros as sampling sets

Result under examination (Lean, conditional on RH): for N ≥ 1, real x_1..x_N, T ≥ e^24·N,
Σ_{|γ|≤T} |Σ_{n≤N} x_n n^ρ|² ≥ (T/100)·Σ x_n² n, i.e. with b_n = x_n√n:
Σ_{|γ|≤T} |Σ_{n≤N} b_n n^{iγ}|² ≥ (T/100)·Σ b_n².
Notation used below: ‖b‖² = Σ|b_n|²; D(t) = Σ_{n≤N} b_n n^{it}; zeros are counted with multiplicity.

## Q1. Beurling–Landau, Seip / Ortega-Cerdà–Seip, Olevskii–Ulanovskii: what density theory says, and whether a constant lower bound at (a constant above) critical density is expected

### Takeaway
For a single-interval spectrum, the classical theory gives sufficiency for separated sets *strictly* above critical density (Beurling), necessity of critical density for any bounded spectrum (Landau), and a delicate critical case. At the critical density, Ortega-Cerdà–Seip characterise sampling through de Branges spaces and show it depends on a logarithmic excess in the counting function. Density never fixes the frame constants. For disconnected spectra no density condition is sufficient (Olevskii–Ulanovskii). So nothing in this theory yields the zeta-zero inequality. The zeros are not uniformly well spaced (they have gaps over 3.18 times the average under RH). The space is a finite-dimensional space of almost-periodic sums on [−T, T], not PW(ℝ). And at T = C·N the zeros exceed the bandwidth density only by an additive constant (1/2π)·log(C/2π), so the density ratio tends to 1 (see Inferences).

### Cited Findings
- Landau's paper: H. J. Landau, "Necessary density conditions for sampling and interpolation of certain entire functions", Acta Math. 117 (1967), 37–52 — [Project Euclid PDF](https://projecteuclid.org/journals/acta-mathematica/volume-117/issue-none/Necessary-density-conditions-for-sampling-and-interpolation-of-certain-entire/10.1007/BF02395039.pdf); same bibliographic data in the reference lists of [Olevskii–Ulanovskii 2015](https://arxiv.org/abs/1512.01437) and [Ortega-Cerdà–Seip](https://arxiv.org/abs/math/0005092). Some indexers date it 1966 rather than 1967 ([search summary of indexing sites](https://portal.mardi4nfdi.de/wiki/Publication:2526236)). - Definitions as used by Olevskii–Ulanovskii: a uniformly discrete Λ is a set of stable sampling (SS) for PW_S if "‖f‖₂² ≤ C Σ_{λ∈Λ} |f(λ)|², ∀f ∈ PW_S". The densities are the Beurling uniform densities D^±(Λ) = lim_{l→∞} inf/sup_a #(Λ∩(a,a+l))/l — [Olevskii–Ulanovskii, "On the duality between sampling and interpolation" (arXiv 1512.01437)](https://arxiv.org/abs/1512.01437).
- Beurling (Bernstein space B_σ, spectrum [−σ,σ]), as stated by Olevskii–Ulanovskii, Theorem 1: "(i) ([Be89a]) Λ is an SS for Bσ if and only if D−(Λ) > σ/π. (ii) ([Be89b]) Λ is an IS for Bσ if and only if D+(Λ) < σ/π." Fourier 7 (1957), 293–314. Beurling deduced the PW sampling theorem from the Bernstein one "by using the so-called linear balayage operator ([Be89a], p. 349)" — [arXiv 1512.01437](https://arxiv.org/abs/1512.01437).
- Landau's theorem as printed in Olevskii–Ulanovskii, Theorem 3: "Let Λ be a u.d. set and S a bounded set. (i) If Λ is an SS for PW_S then D−(Λ) ≥ mes(S)/π; (ii) If Λ is an IS for PW_S then D+(Λ) ≤ mes(S)/π." With their convention f(x) = (2π)^{−1/2}∫_S e^{−itx}F(t)dt, consistency with Theorem 2 (where mes S = 2σ and the threshold is σ/π) requires mes(S)/(2π); the printed "/π" looks like a typo. A simpler proof of Landau's theorem is in Nitzan–Olevskii, C. R. Math. 350 (2012), 509–512 — [arXiv 1512.01437](https://arxiv.org/abs/1512.01437).
- Disconnected spectra: "When the spectrum S is a disconnected set, already when S is a union of two disjoint intervals, simple examples show that no sharp sufficient condition for sampling and interpolation can be formulated in terms of some density of Λ. However, H. Landau discovered that the necessity of the density conditions … is still valid in the general case" — [Olevskii–Ulanovskii 2015](https://arxiv.org/abs/1512.01437).
- Ortega-Cerdà–Seip, "Fourier frames", Ann. of Math. (2) 155 (2002), no. 3, 789–806 (arXiv math/0005092). It solves the Duffin–Schaeffer (1952) problem of characterising the real frequency sequences that generate Fourier frames, equivalently the sampling sequences for PW (type π) — [arXiv abstract](https://arxiv.org/abs/math/0005092), [Annals page](https://annals.math.princeton.edu/2002/155-3/p03).
- Ortega-Cerdà–Seip, Theorem 1: "A separated sequence Λ of real numbers is sampling for PW if and only if there exist two entire functions E, F ∈ HB such that (i) H(E) = PW, (ii) Λ constitutes the zero sequence of EF + E*F*." They also note that a sampling sequence always contains a separated sampling subsequence — [arXiv math/0005092](https://arxiv.org/abs/math/0005092).
- Ortega-Cerdà–Seip on density: elementary sufficiency is "Λ is sampling if there exist positive constants ε and C such that nΛ(b) − nΛ(a) ≥ (1 + ε)(b − a) − C for all a < b", essentially Duffin–Schaeffer's result. Landau's inequality (their Theorem B) reads "If Λ is a separated sampling sequence for PW, then nΛ(b) − nΛ(a) ≥ b − a − A log+(b − a) − B", and it "is best possible". Together these give "Λ is sampling if D−(Λ) > 1 and fails to be sampling if D−(Λ) < 1" — [arXiv math/0005092](https://arxiv.org/abs/math/0005092).
- Ortega-Cerdà–Seip on structure: by Seip (J. Funct. Anal. 130 (1995), 131–160), when D−(Λ) > 1 there is a complete interpolating subsequence, "but an example was given of a sampling sequence Λ for which no subsequence is a complete interpolating sequence" — [arXiv math/0005092](https://arxiv.org/abs/math/0005092).
- Critical density is decided by a logarithmic excess (Ortega-Cerdà–Seip, Theorem 2). For λ_k + ψ(λ_k) = k: "(i) If ψ′(x) = 1/O(x) … and ψ induces a logarithmically regular partition, then Λ(ψ) is sampling for PW. (ii) If ψ′(x) = o(1/x) … then Λ(ψ) is not sampling for PW." In words, "Λ is sampling if and only if ψ(x) tends to ∞ at least as fast as log+ x … A sequence is sampling if and only if it constitutes a sufficiently large deviation from Z." — [arXiv math/0005092](https://arxiv.org/abs/math/0005092).
- Olevskii–Ulanovskii, *Functions with Disconnected Spectrum: Sampling, Interpolation, Translates*, AMS University Lecture Series 65 (2016). Its lectures include "Disconnected spectrum" and "Universal sampling", and the main focus is on recent progress such as universal sampling sets — [AMS bookstore](https://bookstore.ams.org/ULECT/65), [AMS ULECT 65 page](https://www.ams.org/publications/authors/books/postpub/ulect-65).
- Universal sampling: Olevskii–Ulanovskii, "Universal sampling and interpolation of band-limited signals", GAFA 18 (2008), 1029–1052 — [DOI](https://www.doi.org/10.1007/S00039-008-0674-7). Per search summaries of later literature: no universal sampling set exists if the spectrum may be an arbitrary bounded measurable set; under topological restrictions on the spectra universal sets do exist, and their construction is a perturbation of an arithmetic progression. Matei–Meyer showed that "simple quasicrystals" (cut-and-project sets) are universal sampling sets, and a 2014 note shows that in the critical case an arithmetic condition decides universal stable and non-redundant sampling — [2014 Comptes Rendus note (as summarised)](https://comptes-rendus.academie-sciences.fr/mathematique/item/10.1016/j.crma.2014.05.006.pdf). These summaries are secondary; the original abstracts were not read.

### Inferences
- **Density bookkeeping (normalisation).** The frequencies are log n ∈ [0, log N]; recentred, the spectrum is [−σ, σ] with σ = (log N)/2, so the Beurling/Nyquist density is σ/π = (log N)/(2π). The ordinates near height t have density (1/2π)log(t/2π) (from N(T) ~ (T/2π)log T; see [Goldston–Trudgian–Turnage-Butterbaugh](https://arxiv.org/abs/2201.10676)). At t ≈ T = C·N the density is (1/2π)(log N + log(C/2π)). The ratio to Nyquist tends to 1 as N → ∞, and the excess is additive: (1/2π)·log(e^24/2π) ≈ 3.5 for C = e^24. Below height 2πN the zeros are *sparser* than Nyquist. So in density terms the Lean theorem is "critical density plus an additive constant", which sits in the delicate near-critical regime (compare Ortega-Cerdà–Seip Theorem 2). In length terms it is "T a constant factor beyond the crossover T* = 2πN".
- Beurling's sufficiency is qualitative, and frame bounds depend on structure, not density. In PW-type spaces a gap of length L much larger than the Nyquist spacing π/σ supports functions concentrated in the gap (Landau–Pollak–Slepian concentration, the eigenvalue problem Landau used), which drives the lower frame bound towards 0. Under RH there are infinitely many gaps exceeding 3.18 times the average spacing ([Bui–Milinovich](https://arxiv.org/abs/1410.3635)). At T = e^24·N such a gap, 3.18·2π/log(T/2π), exceeds the Nyquist spacing 2π/log N once log N > 22.16/2.18 ≈ 10.2. So generic band-limited sampling theory cannot give the result for all large N. It must use (a) that a length-N Dirichlet polynomial cannot concentrate on scales ≪ N (its |D|² is equidistributed at scales ≫ N, by Montgomery–Vaughan; see Q2) and (b) the arithmetic of the zeros (explicit formula). This agrees with the coordinator's framing.
- The Dirichlet-polynomial space has dimension N, far below the Landau–Pollak–Slepian dimension ≈ T·log N/(2π) of band-limited functions on [0, T]. Landau-type dimension counting alone would allow far sparser samples. What forces the threshold T ≍ N is the frequency resolution (the frequency gap ≈ 1/N at log N; Ingham, Q2) together with the arithmetic of the zeros (approximate functional equation, Q5). Both give the same crossover T ≈ 2πN.

## Q2. Ingham-type inequalities, Montgomery–Vaughan, and discrete (Marcinkiewicz–Zygmund / "lower large sieve") analogues

### Takeaway
The continuous side is classical and sharp. Ingham gives the inverse inequality for |I| > 2π/γ. Montgomery–Vaughan give ∫_0^T|Σ a_n n^{−it}|² = Σ|a_n|²(T + O(n)), i.e. a Riesz sequence on [0,T] once T ≫ N. Selberg/Beurling extremal functions give sharp large-sieve constants. Discrete lower bounds (MZ, sampling) are classically proved under a covering or maximal-gap hypothesis (Gröchenig-type irregular sampling, Wirtinger), or from Selberg-type minorants for *separated* nodes. Zeta zeros violate maximal-gap hypotheses, and the Wirtinger argument is exactly what Hall and Bui–Milinovich use to *prove* large gaps exist.

### Cited Findings
- Ingham's theorem, as stated by Jaming–Komornik (Theorem A): for uniformly separated Λ with uniform gap γ(Λ), the direct inequality ∫_I |Σ c_λ e^{iλx}|² ≪ Σ|c_λ|² holds for every bounded interval. "The inverse inequality Σ|cλ|² ≪ ∫_I |Σ cλ e^{iλx}|² dx holds for every bounded interval I of length > 2π/γ(Λ)", and "The condition |I| > 2π/γ(Λ) is the best uniform condition for all uniformly separated sets, but it can be weakened for individual uniformly separated sets." Reference: A. E. Ingham, "Some trigonometrical inequalities with applications to the theory of series", Math. Z. 41 (1936), 367–379 — statement from [Jaming–Komornik, arXiv 1903.07804](https://arxiv.org/abs/1903.07804); volume and pages from [Negreanu–Zuazua, CDC-ECC 2005 (via search summary)](https://skoge.folk.ntnu.no/prost/proceedings/cdc-ecc05/pdffiles/papers/0922.pdf).
- Haraux recognised the usefulness of Ingham's theorem in control theory. A Haraux variant holds for |I| > 2π/γ(Λ∖F) after removing a finite set F. Baiocchi–Komornik–Loreti have "Ingham type theorems and applications to control theory" and "Ingham–Beurling type theorems with weakened gap conditions" (venues not captured) — [Jaming–Komornik](https://arxiv.org/abs/1903.07804).
- Montgomery–Vaughan, "Hilbert's inequality", J. London Math. Soc. (2) 8 (1974), 73–82 — [Encyclopedia of Mathematics, "Dirichlet polynomial"](https://encyclopediaofmath.org/wiki/Dirichlet_polynomial); also [Bui–Florea–Milinovich ref. [20]](https://arxiv.org/abs/2310.03949). Its Corollary 3 is the mean-value theorem for Dirichlet polynomials that Bui–Florea–Milinovich call "Montgomery-Vaughan's mean-value theorem for continuous averages [of] Dirichlet polynomials [20, Corollary 3]" — [arXiv 2310.03949](https://arxiv.org/abs/2310.03949). Lubinsky restates it as (1/T)∫_0^T|Σ a_n n^{−it}|² dt = Σ|a_n|² + O((1/T)Σ n|a_n|²), uniformly — [Lubinsky](https://lubinsky.math.gatech.edu/Research%20papers/DirichletMeanValueJan2014Rohrs.pdf) (via search summary).
- Hilbert-type inequality behind it (Weber's Lemma 5): if |λ_m − λ_n| ≥ δ for m ≠ n then |Σ_{m≠n} x_m y_n/(λ_m − λ_n)| ≤ (π/δ)(Σ|x_m|²)^{1/2}(Σ|y_n|²)^{1/2} — [Weber, "Dirichlet polynomials: some old and recent results…", arXiv 0907.4931](https://arxiv.org/abs/0907.4931). The weighted form, with δ_n the gap at λ_n and a constant γ_0, is Lemma 12 in [Olsen–Saksman](https://arxiv.org/abs/0907.2708). For the optimal weighted constant C, π ≤ C < π + 1 is known and C = π is conjectured — [seminar abstract](https://researchseminars.org/talk/CANT2022/5/).
- Wirtinger-type inequalities, as used for zeta gaps. "(i) If f(a) = f(b) = 0, then ∫_a^b|f|² ≤ ((b−a)/π)² ∫_a^b|f′|²; (ii) If f(a) = f(b) and ∫_a^b f = 0, then ∫|f|² ≤ ((b−a)/2π)² ∫|f′|²." Hall's method reduces the existence of large gaps to such inequalities plus mean values, giving Λ > 2.63 (Hall), Λ > 2.76 (Bredberg) and Λ > 3.18 (Bui–Milinovich) — [Bui–Milinovich, arXiv 1410.3635](https://arxiv.org/abs/1410.3635).
- Gröchenig, "Reconstruction algorithms in irregular sampling", Math. Comp. 59 (1992), 181–194 (DOI 10.1090/S0025-5718-1992-1134729-0). It gives a constructive solution of irregular sampling for band-limited functions and addresses quantitative questions (feasible sampling densities, convergence speed) — [AMS record (via search summary)](https://www.ams.org/mcom/1992-59-199/S0025-5718-1992-1134729-0/).
- Gröchenig (2019/2020): "a sampling theorem is simply a Marcinkiewicz-Zygmund inequality (upper and lower) for a fixed function space, and some of the first Marcinkiewicz-Zygmund inequalities for scattered points on the torus (or non-uniform sampling points) were derived in this context [22]". [22] is Gröchenig, "A discrete theory of irregular sampling", Linear Algebra Appl. 193 (1993), 129–150 — [Gröchenig, "Sampling, Marcinkiewicz–Zygmund inequalities, approximation, and quadrature rules", arXiv 1909.07752](https://arxiv.org/abs/1909.07752).
- Selberg and extremal functions. J. D. Vaaler, "Some extremal functions in Fourier analysis", Bull. Amer. Math. Soc. 12 (1985), 183–215 (pages per [Carneiro–Vaaler II, arXiv 0809.4050](https://arxiv.org/abs/0809.4050); another list gives 183–216). Selberg rediscovered Beurling's function "and recognized its importance in connection with the large sieve inequality" — [Carneiro–Vaaler II](https://arxiv.org/abs/0809.4050). The sharp large sieve constant is N − 1 + δ^{−1} — [lecture notes](https://personal.science.psu.edu/rcv4/LargeSieve.pdf) (via search summary). Moitra replaced Selberg's majorant by the extremal minorant to get a lower bound on the smallest singular value of Vandermonde matrices with separated nodes, a "lower large sieve" — [arXiv 1701.02538 (as summarised)](https://arxiv.org/abs/1701.02538).

AMS 84 (1978), 547–567.

### Inferences
- **Equivalent form of the theorem.** By Montgomery–Vaughan, {n^{it}}_{n≤N} is a Riesz sequence in L²[0,T] with bounds T ± O(N). For T ≥ e^24·N and real b this gives ∫_{−T}^{T}|D|² = 2T‖b‖²(1 + O(e^{−24})). The Lean theorem is then equivalent, up to that factor, to the unweighted MZ-type inequality Σ_{|γ|≤T}|D(γ)|² ≥ (1/200)·∫_{−T}^{T}|D|². With density weights w_γ ≈ 2π/log(γ/2π), the normalised lower MZ constant is of order 1/log T. As argued in Q5, this loss relative to the mean is *unavoidable* when T/N is bounded.
- **Ingham threshold.** For the frequencies log n, n ≤ N, the minimal gap is log(N/(N−1)) ≈ 1/N, so Ingham's uniform condition is T > 2πN. This is the same crossover as "zero density = Nyquist density", log(T/2π) = log N, and as the length T/2π in the approximate functional equation. The regime T ≍ N is therefore the natural one.
- **Why maximal-gap methods fail.** The maximal-gap (Gröchenig/Wirtinger) route needs every gap in [0,T] below the Nyquist spacing. The zeros violate this infinitely often (λ > 3.18 under RH; conjecturally λ = ∞). Wirtinger is in fact the tool that proves large gaps exist. The natural replacement is a minorant m ≤ 1_{[−T,T]}: Σ_γ|D(γ)|² ≥ Σ_γ|D(γ)|²m(γ), with the right side evaluated by the Guinand–Weil explicit formula. This is the Selberg/Vaaler minorant idea with zeros as nodes, in the tradition of Montgomery–Odlyzko (Q5) and Carneiro–Chandee–Littmann–Milinovich (Q4).

## Q3. Hilbert spaces of Dirichlet series (Hedenmalm–Lindqvist–Seip, Olsen–Saksman, Olsen–Seip, Saksman–Seip, …): sampling and interpolation results, and whether any use zeta zeros

### Takeaway
This theory studies H² = {Σ a_n n^{−s} : Σ|a_n|² < ∞}. Interpolating sequences are characterised *locally* in the half-plane σ > 1/2 (Olsen–Seip). On σ = 1/2 there is a Montgomery–Vaughan-based local embedding, and Olsen–Saksman prove an explicit frame estimate for weighted exponentials at logarithmic frequencies, the *dual* configuration to ours. I found no result in this literature, including the Saksman–Seip problem list, that treats zeta zeros as sampling or interpolating sets for Dirichlet polynomials.

### Cited Findings
- Hedenmalm–Lindqvist–Seip, "A Hilbert space of Dirichlet series and systems of dilated functions in L²(0,1)", Duke Math. J. 86 (1997), 1–37. H² consists of functions analytic in Re s > 1/2, with reproducing kernel printed as "k_s(w) = ζ(s + w)" (with the usual convention it is ζ(w + s̄)), and via the Bohr correspondence H² ≅ H²(𝕋^∞) — [Saksman–Seip, arXiv 1601.01616](https://arxiv.org/abs/1601.01616).
- Olsen–Seip, "Local interpolation in Hilbert spaces of Dirichlet series", Proc. AMS 136 (2008), 203–212: "a bounded sequence of points in the half-plane σ > 1/2 is an interpolating sequence for H if and only if it is an interpolating sequence for the Hardy space H² of the same half-plane." Similar local results hold for Bergman- and Dirichlet-type spaces of Dirichlet series — [arXiv math/0608506](https://arxiv.org/abs/math/0608506), [PAMS](https://www.ams.org/journals/proc/2008-136-01/S0002-9939-07-08955-1).
- Local embedding on σ = 1/2: for F ∈ H² and every bounded interval I, lim_{σ→1/2+} ∫_I|F(σ+it)|² dt ≤ C‖F‖²_{H²} with C depending only on |I|. Olsen–Saksman attribute this to Montgomery and to Hedenmalm–Lindqvist–Seip — [Olsen–Saksman, arXiv 0907.2708](https://arxiv.org/abs/0907.2708).
- Olsen–Saksman, "On the boundary behaviour of the Hardy spaces of Dirichlet series and a frame bound estimate", J. Reine Angew. Math. 663 (2012), 33–66 (venue per [Saksman–Seip ref. [71]](https://arxiv.org/abs/1601.01616)). Their Lemma 9: for an interval I the system Ω_I = {…, 3^{it}/√3, 2^{it}/√2, 1, 2^{−it}/√2, …} is a frame for L²(I), i.e. A_I‖f‖² ≤ |f̂(0)|² + Σ_{n≥2}(|f̂(log n)|² + |f̂(−log n)|²)/n ≤ B_I‖f‖². The optimal lower bound A_I decays like |I|^{−c|I|} for large |I|, with (22) giving exponents between roughly (1−ε)|I|/(π log π) and (1+ε)6|I|/(π log 2). They also show |I| ≤ B_I ≤ |I| + d with d ≤ 13.3138…, and A_I, B_I → 2π as |I| → 0. Their remark: "This is of independent interest since explicit bounds for non-trivial frames are difficult to obtain." — [arXiv 0907.2708](https://arxiv.org/abs/0907.2708).
- Saksman–Seip, "Some open questions in analysis for Dirichlet series" (arXiv 1601.01616; in *Recent Progress on Operator Theory and Approximation in Spaces of Analytic Functions*, Contemp. Math. 679 (2016), 179–191 per [research.fi](https://research.fi/en/results/publication/0277791316)). Problem 2.1 (embedding problem): "Is the L^p integral of a Dirichlet polynomial … over any segment of fixed length on the vertical line Re s = 1/2 bounded by a universal constant times ‖·‖_{H^p}? This is known to hold for p = 2". They also pose Carleson-measure problems and dual questions on interpolating sequences for H^p. The list mentions Fourier frames as a tool but never zeta zeros as sampling sets — [arXiv 1601.01616](https://arxiv.org/abs/1601.01616). (Checked by full-text search of the arXiv PDF for "sampling", "interpolat", "zeros of", "frame".)
- Related, but about zero sets rather than sampling: Seip, "Zeros of functions in Hilbert spaces of Dirichlet series", Math. Z. 274 (2013), 1327–1339; standard background is Seip, *Interpolation and Sampling in Spaces of Analytic Functions*, AMS University Lecture Series 33 (2004) — [Saksman–Seip refs](https://arxiv.org/abs/1601.01616), [Olsen–Seip refs](https://arxiv.org/abs/math/0608506).

### Inferences
- In H² the zeros on σ = 1/2 are boundary points where point evaluation is unbounded. "Zeros as a sampling set" therefore only makes sense for finite-length polynomials, or in local L² form via the Montgomery–Vaughan embedding. The Lean statement is a finite-dimensional MZ inequality, not a sampling or interpolation theorem in the HLS sense, which may explain why this literature never addresses it.
- Olsen–Saksman's Lemma 9 is the *dual* problem: PW(I) sampled at the points ±log n with weights 1/n, which are the frequencies of our problem. Its lower frame bound decays super-exponentially in |I|, a warning that systems built on logarithmic frequencies can be badly conditioned. In the zeta problem the roles of points and frequencies are swapped, and the explicit formula, which links {γ} and {log p^k}, mediates.

### Gaps
- I did not find, and could not rule out, sampling or interpolation results by Brevig, Ortega-Cerdà, Seip and coauthors aimed at Dirichlet *polynomials* on σ = 1/2. Only web and arXiv searches were run; MathSciNet and zbMATH were not accessed.
- The Hedenmalm–Lindqvist–Seip Duke paper was not read directly.

## Q4. Zeros of ζ (or of L-functions) as sampling, interpolating, frame or Riesz sets; crystalline measures and quasicrystals; the explicit formula as a sampling or Poisson formula

### Takeaway
I found no paper treating {γ} as a sampling, frame or Riesz-basis set for {n^{iγ}} or {e^{iγt}} in the sense of the Lean theorem. The closest structural facts are:
- **de Branges.** Under RH, E_ξ(z) = ξ(1/2−iz) + ξ′(1/2−iz) is Hermite–Biehler (Lagarias), and the Weil hermitian form, i.e. the spectral side of the explicit formula as a sum over zeros, *is* a de Branges norm (Suzuki), with the zeros as eigenvalues of a self-adjoint operator. This is an exact "sampling identity at the zeros", but for a de Branges space, not for Dirichlet polynomials.
- **Crystalline measures.** Guinand's explicit-formula example is a Poisson-type formula but, per Kurasov–Sarnak, not a Fourier quasicrystal even under RH.
- **Nyman–Beurling.** Lower bounds in which the zeros act as sampling points for a Dirichlet-type approximation problem (Báez-Duarte–Balazard–Landreau–Saias; Burnol).
- **Pair correlation.** Reproducing-kernel and extremal-function methods (Carneiro–Chandee–Littmann–Milinovich).

### Inferences
- **de Branges view.** By de Branges' theorem on orthogonal sets of reproducing kernels at the zeros of A = (E + E^♯)/2 (de Branges, *Hilbert Spaces of Entire Functions*, 1968, Theorem 22; recalled from memory, not re-verified here), under RH the ordinates γ (the zeros of A(z) = ξ(1/2−iz)) give an orthogonal set {K(γ,·)} in H(E_ξ), complete unless A ∈ H(E_ξ). This yields an exact orthogonal sampling identity ‖F‖² = Σ_γ|F(γ)|²/K(γ,γ) in that space, consistent with Suzuki's "zeros as eigenvalues" remark. H(E_ξ) is not the space of Dirichlet polynomials, so the Lean theorem is not a corollary. It can, however, be read as a *quantitative* Weil-positivity statement: RH gives Σ_γ ĝ(γ) ≥ 0 for g = h*h̃, while the Lean theorem bounds the spectral sum Σ_γ |D(γ)|²·1_{[−T,T]}(γ) below by cT‖b‖².
- **Fourier-quasicrystal view.** The zeros' counting measure minus its smooth density has Fourier transform supported on {±log p^k} (Guinand–Weil) plus an archimedean continuous part, which is why it is not a Fourier quasicrystal (Kurasov–Sarnak). The sampling problem uses exactly this duality, with points {γ} and frequencies {log n}. The prime-power side produces the off-diagonal "Landau form" Σ b_{kn} b̄_n Λ(k)/√k (Q5).
- **L-functions.** The discrete-mean-value and explicit-formula machinery exists for other L-functions: Conrey–Iwaniec, "Spacing of zeros of Hecke L-functions and the class number problem", Acta Arith. 103 (2002) ([ref. in arXiv 2201.10676](https://arxiv.org/abs/2201.10676)), and Hall's method adapted to other L-functions ([Bui–Milinovich](https://arxiv.org/abs/1410.3635)). An analogue of the Lean theorem for L-function zeros is plausible but I found none stated.

## Q5. Does "under RH, Σ_{|γ|≤T}|Σ_{n≤N} b_n n^{iγ}|² ≥ c·T·Σ|b_n|² for T ≥ C·N" (or with T·log(T/N)) appear anywhere? Closest prior results and sharpness

### Takeaway
I did not find the statement anywhere, as theorem, remark or conjecture. Its closest relatives are asymptotic discrete mean values over zeros:
- the Montgomery–Odlyzko method in the Conrey–Ghosh–Gonek formulation, a *smoothed* sum over zeros compared with ∫|A|², for polynomials of length y = T^{1−δ} (or K = T/log²T);
- Bui–Florea–Milinovich's discrete Montgomery–Vaughan theorem (2023): Σ_{0<γ≤T}|Σ_{n≤x} a_n n^{−ρ}|² = N(T)Σ|a_n|²/n − (T/π)Re Σ a_{kn}ā_nΛ(k)/(kn) + O(x log²(xT)Σ|a_n|²/n).

Combined with the classical Conrey–Ghosh–Gonek bound on the Λ-form, the latter already gives the "T·log(T/N)" lower bound, but only for N ≲ T/log²T and with inexplicit constants. The Lean theorem's novelty is the range N up to T/e^24 (no log² loss), explicit constants, unsmoothed point sampling, and uniformity. Its range hypothesis is necessary up to the constant: the inequality fails at T = N (rigorous, under RH, for N ≥ 10⁴) and for T ≤ (2π − ε)N asymptotically, because partial sums of ζ nearly vanish at the zeros.

### Inferences
- **What Bui–Florea–Milinovich already give (my derivation).** Put a_n = b_n√n. Then Σ|a_n|²/n = ‖b‖² and a_{kn}ā_n/(kn) = b_{kn}b̄_n/√k, so Theorem 3.1 reads Σ_{0<γ≤T}|D̃(γ)|² = N(T)‖b‖² − (T/π)Re Q(b) + O(N log²(NT)‖b‖²), where D̃(γ) = Σ b_n n^{−iγ} and Q(b) = Σ_{kn≤N} b_{kn}b̄_nΛ(k)/√k.
  - The CGG/AM–GM bound |b_{kn}b̄_n|/√k ≤ ½(|b_{kn}|² + |b_n|²/k) gives |Q| ≤ ½Σ_n|b_n|²[log(N/n) + O(1) + log n] = ½(log N + O(1))‖b‖².
  - With N(T) = (T/2π)log(T/2πe) + O(log T), and adding the conjugate sum for −T ≤ γ < 0: Σ_{|γ|≤T}|D(γ)|² ≥ (T/π)(log(T/N) − O(1))‖b‖² − O(N log²T)‖b‖².
  - So the "T·log(T/N)" lower bound holds for T ≥ C·N·log²T (roughly). The Lean theorem extends the range to T ≥ e^24·N, removing the log² loss, with explicit constants and without smoothing. This is the precise sense of "no log loss": in the range.
- **The log T loss in the constant is unavoidable when T ≍ N.** Take b_n = n^{−1/2} (x_n = 1/n). Then Re Q = Σ_n n^{−1}(log(N/n) + O(1)) = ½log²N + O(log N) and ‖b‖² = log N + O(1). Theorem 3.1 gives Σ_{0<γ≤T}|D̃|² = (T/2π)‖b‖²(log(T/N) + O(1)) + O(N log²T‖b‖²), which is rigorous wherever that theorem's error term is negligible, e.g. N = T/log³T. This is of order T·log(T/N)·‖b‖², much smaller than the "mean" (T/π)log T·‖b‖² when T/N is small. Hence:
  - (i) the natural conjecture is Σ_{|γ|≤T}|D(γ)|² ≫ T·log(T/N)·‖b‖² for T ≥ C·N;
  - (ii) for T = C·N with fixed C, a bound of the form c·T·‖b‖² (as in the Lean theorem) is heuristically the right order. This is heuristic at N ≍ T, since Theorem 3.1 is not effective there.
- **The range hypothesis is necessary (rigorous counterexample under RH).** Take x_n = 1/n and N = T. Under RH, n^{ρ−1} = n^{−ρ̄} and |Σ_{n≤N} n^{−ρ̄}| = |Σ n^{−ρ}|. Arias de Reyna (x = N, 0 < γ ≤ T = N, ζ(ρ) = 0) gives |Σ_{n≤N} n^{−ρ}| ≤ N^{1/2}/|ρ| + (29/14)N^{−1/2}. Using Σ_ρ 1/|ρ|² = 2 + γ_E − log 4π ≈ 0.046191 (standard identity, e.g. Davenport ch. 12, not re-verified here), the left side is at most 2N·0.046191 + 2(29/14)²·2N(T)/N. The right side is (T/100)·H_N. My computation with N(T) ≈ (T/2π)log(T/2πe) + 7/8:

  | N = T | LHS bound | RHS |
  |---|---|---|
  | 10⁴ | 941 | 979 |
  | 10⁵ | 9262 | 12090 |
  | 10⁶ | 92413 | 143927 |
  | 10⁸ | 9.24×10⁶ | 1.90×10⁷ |

  So the inequality fails at T = N for all these N, and in fact for every N ≥ 10⁴: the margin N(H_N/100 − 0.0924) grows linearly, while the N(T)-dependent term grows only logarithmically (about 17.5 at N = 10⁴ and 24 at N = 10⁵), so using main terms for N(T) is immaterial. Asymptotically, Titchmarsh 4.11 with C > 1 shows that, for any constant c > 0 in place of 1/100, the inequality fails for T ≤ (2π − ε)N once N is large. A polynomial of length N′ = ⌈T/(2π − ε)⌉ ≤ N extends the failure to every sufficiently large T with T ≤ (2π − ε)N. So the true threshold constant C* (for c = 1/100, N → ∞) lies in [2π, e^24], and the zeta zeros behave like a Beurling-type critical-density phenomenon: failure below the crossover T ≈ 2πN, where zero density = Nyquist density = Ingham resolution.
- **Upper frame bound side.** CGG's estimate also gives h(c) ≤ (2 − δ)c for y = T^{1−δ}, i.e. an asymptotic *upper* smoothed bound M_2(c) ≲ 2c·M_1. Together with Theorem 3.1 this shows the upper bound Σ_γ|D(γ)|² ≲ (T/π)(log T + log N)‖b‖² is routine, so the novelty of the Lean result is on the lower-bound side.
