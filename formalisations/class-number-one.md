# Gauss's class number one problem (Baker, Heegner, Stark)

**Lean:** `ClassNumberOne.classNumber_eq_one_iff` (`lib/pnt/ClassNumberOne.lean`), with `QuadPrincipal`
(`lib/pnt/QuadPrincipal.lean`) and the certificate `ClassNumberOneCertDefs`, `ClassNumberOneCertP0`, …, `P3`:

```lean
theorem classNumber_eq_one_iff (hK : Module.finrank ℚ K = 2) (hc : InfinitePlace.nrRealPlaces K = 0) :
    classNumber K = 1 ↔
      discr K = -3 ∨ discr K = -4 ∨ discr K = -7 ∨ discr K = -8 ∨ discr K = -11 ∨ discr K = -19 ∨
        discr K = -43 ∨ discr K = -67 ∨ discr K = -163
```

for a number field `K`, with Mathlib's `NumberField.classNumber`, `NumberField.discr` and
`NumberField.InfinitePlace.nrRealPlaces`. In words: an imaginary quadratic field has class number one if and only if
its discriminant is one of the nine. The theorem depends on `propext`, `Classical.choice` and `Quot.sound` only
(`lib/check/CheckAll.lean`).

## Source and attribution

- The theorem is K. Heegner's (*Diophantische Analysis und Modulfunktionen*, Math. Z. 56 (1952)), A. Baker's (*Linear
  forms in the logarithms of algebraic numbers*, Mathematika 13 (1966)) and H. M. Stark's (*A complete determination of
  the complex quadratic fields of class-number one*, Michigan Math. J. 14 (1967)). The problem is Gauss's
  (*Disquisitiones Arithmeticae*, art. 303), for forms.
- The proof here is none of theirs. It is the proof that a zero-free half-plane makes possible: Littlewood's bound for
  `L(1, χ)` (J. E. Littlewood, Proc. London Math. Soc. 27 (1928), under GRH) with explicit constants, the class number
  formula, and a finite search. That such a proof exists once Landau–Siegel zeros are excluded with explicit constants
  is classical; OpenAI's companion preprint states the effective bound `h(D) ≫ √|D|/log log |D|` as a consequence of the
  half-plane ([openai-half-plane.md](openai-half-plane.md)).
- **It is not the first proof of this kind to be checked by Lean's kernel.** T. Tao posted a challenge on 20 October
  2026: to bound a hypothetical tenth field with one of the new arguments, without Heegner's method. The repository
  `github.com/DrMurphyIsIn/tenth-discriminant` (found by search on 9 November 2026; its README read, its Lean not)
  reports a kernel-checked proof from OpenAI's Lean proof of the half-plane `Re s > 7/8`, with the bound `d ≤ 652` from
  the Chowla–Selberg formula and split-prime certificates below it, and a second proof with no `L`-function. The
  repository `github.com/WangFrankie/BakerHeegnerStark` reports a formalisation of Heegner's argument. Neither was
  used here, and this note claims no priority.
- What is the library's own: the derivation on its own proof of the half-plane at `11/12` (no file of OpenAI's release
  is imported), through its explicit bound `|D_K| < 2.5·10⁷`, which leaves a search of three million cases to the
  kernel, and the statement for an abstract number field against Mathlib's `classNumber` and `discr`.

## The proof

**Only if.** Let `K` have class number one.

1. `|D_K| < 2.5·10⁷` (`ClassNumberSharp.abs_discr_lt_of_classNumber_eq_one`): `h_K ≥ √|D_K|/(85(52 + log log(|D_K| +
   2)))`, from the class number formula (`QuadKronecker.classNumber_formula`) and the lower bound for `L(1, χ)` with
   explicit constants (`LittlewoodSharp.norm_LFunction_one_bounds_sharp`), which uses the half-plane.
2. An element of `𝓞 K` whose norm is a prime `p` up to sign forces `|D_K| ≤ 4p` (`QuadPrincipal.abs_discr_le_of_norm`).
   With `K = ℚ(√d)`, `d < 0` squarefree (`QuadRing.exists_sqrt`, `QuadPrincipal.neg_of_nrRealPlaces`): if
   `d ≡ 1 (mod 4)` the norm of `u + v(1 + √d)/2` is `((2u + v)² + |d|v²)/4` and `D_K = d`; if `d ≡ 2, 3 (mod 4)` the
   norm of `u + v√d` is `u² + |d|v²` and `D_K = 4d` (`QuadPrincipal.norm_eq_of_basis` with `QuadRing`'s bases). A value
   `p` with `v = 0` would make `p` a square.
3. So a prime that splits or ramifies has `|D_K| ≤ 4p`: the prime ideal above it has norm `p` and is principal
   (`QuadPrincipal.abs_discr_le_of_split`, `QuadPrincipal.abs_discr_le_of_ramified`).
4. With the splitting law (`QuadSplit`): for `d ≡ 2, 3 (mod 4)` the prime `2` ramifies, so `4|d| ≤ 8` and
   `D_K ∈ {−4, −8}`; for `d ≡ 1 (mod 8)` it splits, so `|d| ≤ 8` and `D_K = −7`; for `d ≡ 5 (mod 8)`, `d` is not a
   square modulo any odd prime `p` with `4p < |d|`.
5. The finite search (`ClassNumberOne.heegner_or_good`): every `n ≡ 3 (mod 8)` below `25 600 171` is one of
   `3, 11, 19, 43, 67, 163`, or `−n` is a square modulo an odd prime `p ≤ 67` with `4p < n`.

**If.** Minkowski's bound (Mathlib's `NumberField.exists_ideal_in_class_of_norm_le`) puts an ideal of norm at most
`(2/π)√|D_K|` in every class (`QuadPrincipal.exists_ideal_norm_le`). If every prime up to `B` is inert, every nonzero
ideal of norm at most `B` is generated by a natural number (`QuadPrincipal.isPrincipal_of_inert`): it lies in a prime
ideal, whose rational prime `p` divides its norm, so is inert, so the prime ideal is `p𝓞`, and the quotient has norm
smaller by `p²`. For `D_K = −163` the bound is `8` and the primes `2, 3, 5, 7` are inert; for `−67`, `−43`, `−19`,
`−11` the bounds are `5, 4, 2, 2`; for the other four the bound is `1`.

## The certificate

`ClassNumberOneCert.good n` says that some odd prime `p ≤ 67` has `4p < n` and `−n` a square modulo `p`, read from a
bit mask of the squares modulo `p`. `ClassNumberOneCert.check_0`, …, `check_31` are 32 kernel computations
(`decide +kernel`), each `good n` for `100 000` values `n = base + 8j`; together they cover every `n ≡ 3 (mod 8)` from
`171` to `25 600 163`, and `ClassNumberOne.good_small` the fifteen cases below `171`. The four part files import
`Mathlib.Data.Nat.Notation` only; each took about three and a half minutes of one core here.

- The masks are not trusted: `ClassNumberOne.masks_ok` proves, by a kernel computation, that each `p` of the list has
  no divisor in `[2, p)` and that each set bit of its mask is a square modulo `p`.
- `scripts/gen_class_number_cert.py` writes the certificate's five files; `--check` compares them with the ones in
  `lib/pnt`.
- Only the primes up to `67` are needed. The search is the one that `scripts/littlewood_sharp.py` (section D) made
  numerically.

## Differences from the published theorem

- The statement is for number fields of degree `2` with no real place, by their discriminants, not for `ℚ(√−m)` by
  `m`. The nine discriminants are those of `m = 3, 1, 7, 2, 11, 19, 43, 67, 163`.
- The proof rests on the half-plane, which no referee has read ([openai-half-plane.md](openai-half-plane.md)): the
  theorem is unconditional as a statement checked by the kernel, and its mathematics is as reviewed as its input.
  Heegner's, Baker's and Stark's proofs do not have that dependence. `ClassNumberOne.classNumber_eq_one_of_discr`
  ("if") does not use the half-plane.
- No source was read for this note beyond the statements of the theorem; the argument is the textbook one for
  class number one from a bound on the discriminant.
